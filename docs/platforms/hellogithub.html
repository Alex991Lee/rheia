## 项目标题

在 Windows 上双击部署原生 OpenClaw 的桌面外壳

## 项目描述

OpenClaw 在 Windows 上要跨过 WSL2、Ubuntu、Node.js、网关服务四道门，任何一步出错都得从头再来。Rheia 把这条链做成一次双击：复用机器上已有的 Ubuntu（不另建发行版）、安装官方 npm 包（不 fork 不改源码）、自动选择国内或海外镜像源、用 systemd 托管网关实现开机自启。安装包 3.5 MB，界面基于 PySide6，MIT 协议开源。

## 亮点

- **不重复占磁盘**：复用已有的 WSL2 + Ubuntu，而不是另建一个专属发行版
- **始终是官方那版**：装的是官方 openclaw@latest，官方每出一版立即跟进，文档、插件、issue 区全都对得上
- **开箱即用**：预装 Tavily 搜索、mem9 记忆、office-toolkit、浏览器自动化等 8 项技能与插件，并直装 LibreOffice 与文档处理库，配置好模型就能干活
