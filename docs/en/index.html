What it does

Installs the whole chain

WSL2 + Ubuntu + Node.js + official OpenClaw + a systemd gateway, in one pass. Ready when it finishes.

Reuses your Ubuntu

No dedicated distro. The Ubuntu you already run is the runtime — no second copy on disk.

Always the official build

No fork, no patch. Every upstream release is followed immediately, so you stay on the newest build.

Work-ready out of the box

Once the gateway is up, the shell installs a set in the background:

  • @openclaw/tavily-plugin — web search
  • @mem9/mem9 — persistent memory
  • @weiwei2027/office-toolkit — Word / Excel / PPT / PDF
  • @cindypapa/agent-browser — browser automation
  • @paudyyin/summarize · @pskoett/self-improving-agent · @guipi888/find-skills · @spclaudehome/skill-vetter

Companions are installed too: LibreOffice (the soffice engine), the Chrome kernel, and python-docx / python-pptx / openpyxl / pymupdf / reportlab.

About the UI — full disclosure

On some machines the UI flickers under PySide6 (QtWebEngine). The cause is in Chromium's compositor, not in application code. GPU flags, the D3D11 backend and reduced motion were all tried; they tame part of it, but we cannot guarantee every GPU.

That is a trade-off known at selection time, not an incident. The real fix is on the roadmap: switch languages, buy a commercial licence.
