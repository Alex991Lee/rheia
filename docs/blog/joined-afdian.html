我已经入驻爱发电

2026-11-14

这个项目现在在爱发电有了主页：afdian.com/a/rheiashell

为什么开这个页

Rheia 一直是我一个人在做：安装器、WSL 下的网关管理、图形化运维，还有后面的人格插槽。代码是开源的，但维护、测试和打包都是实打实的时间。爱发电是给愿意支持这件事的人留的一个入口。

现在上面有什么

长期档位，可以按自己意愿支持。产品本体与详细说明在 GitHub 与 Gitee 的 Release 里，一分钱不差——支持不等于解锁，也不影响任何人使用。

我不会做什么

  • 不设付费墙
  • 不锁功能
  • 不做“支持才给下载”

开源就是开源。

后面

新版本、踩坑记录，以及 Personal Slot 的进度，都会在爱发电和仓库里同步。

谢谢每一个已经支持的人。
