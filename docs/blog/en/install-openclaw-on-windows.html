How Rheia installs OpenClaw

About the time it takes to drink a coffee. Measured on a clean environment: 9 minutes 29 seconds from download to a working agent. Real-world time depends on your machine and your network.

1. Install

One installer, every command wrapped. No dependency hunting, no path juggling, no hand-edited WSL config — and no risk of deleting the wrong thing while you poke around.

2. Use

TerminalView and WebView are integrated: the native OpenClaw running inside WSL behaves like a local application. Everyday maintenance has a graphical path, so you are not forced into a bash session.

3. Optional

  • Already running OpenClaw? Install Rheia as the deployment manager only — near-zero extra cost.
  • Only want OpenClaw? Uninstall Rheia and run openclaw dashboard inside WSL, then open it in your browser.

4. Recovery

The installer brings up WSL and the VM automatically when the environment is clean. The gateway runs under systemd, so it returns after a reboot. Installation and resume-after-reboot are hands-off. On first run it self-adjusts against your installed OpenClaw version — a curated dictionary plus disambiguation rules — so Rheia stays aligned with the official release.

5. Uninstall

Install and uninstall are both clean. Nothing is left scattered behind.

6. Data

Data stays local. Nothing is uploaded, nothing is collected, no account is required.

7. Boundaries

No fork, no changes to the official kernel. No hosting, no subscription lock-in. What you install is the current official version, wrapped in a deployment layer.
