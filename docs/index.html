它做的事

一键装好整条链

WSL2 + Ubuntu + Node.js + 官方 OpenClaw + systemd 网关，一次装完，装完就能用。

复用你的 Ubuntu

不另建专属发行版。你机器上已有的 Ubuntu 直接用起来，磁盘不多占一份。

始终是官方那版

不 fork、不打补丁。官方每出一版，我们立即跟进，你拿到的是最新那一版。

与官方 Windows 方案的位置

官方 PowerShell 直装官方 Windows HubRheia
形态命令行安装WinUI 桌面应用桌面外壳
运行时原生 Windows 进程另建 app 专属 WSL 发行版你原有的 WSL2 + Ubuntu
已有 Ubuntu不涉及与之并存，磁盘多一份复用，零浪费
开机自启自行配置托盘systemd 服务，随机器启动
国内下载直连官方源直连官方源国内 / 国际镜像自动切换

装完就能办公

网关连通后，壳会在后台静默装上一批东西：

  • @openclaw/tavily-plugin — 联网搜索
  • @mem9/mem9 — 持久记忆
  • @weiwei2027/office-toolkit — Word / Excel / PPT / PDF
  • @cindypapa/agent-browser — 浏览器自动化
  • @paudyyin/summarize · @pskoett/self-improving-agent · @guipi888/find-skills · @spclaudehome/skill-vetter

配套一并直装：LibreOffice（soffice 引擎）、Chrome 内核、python-docx / python-pptx / openpyxl / pymupdf / reportlab。

关于界面，我们诚实交底

PySide6（QtWebEngine）在部分机器上有界面闪动，成因在 Chromium 合成层，不在业务代码。我们试过 GPU flag、D3D11 后端、减弱动效，能压住一部分，但不能对所有显卡保证。

这是选型时就知道的取舍，不是事故。根治的方向写进了路线图：换语言、买商业许可。
